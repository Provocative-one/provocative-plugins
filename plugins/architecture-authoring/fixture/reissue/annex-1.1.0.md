# Assumptions and exclusions

The following assumptions underpin the offer, as clarified on 25 September 2026.

1. The Trust provides content for every site before its milestone starts.

2. Translators are available for Welsh review.

3. The collections database exports nightly, starting before the first milestone closes.

4. Ticketing stays on its current platform.

5. The Trust approves the wave plan within five business days.

6. The online shop is excluded.

7. Image rights metadata is supplied with the export.
