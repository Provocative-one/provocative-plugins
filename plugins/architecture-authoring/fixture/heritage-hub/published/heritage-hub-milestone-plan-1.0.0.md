# Heritage Hub: milestone plan

Prepared for the Example Heritage Trust.

1. First wave live. Three museum sites run on the shared platform, and an editor's change appears on every affected site within five minutes. Planned duration: about six weeks.

2. Collections Explorer live. Search over the nightly collections export answers each of the Trust's twenty test queries within one second. Planned duration: about five weeks.

3. Second wave and Welsh. All six sites are live, and every page has a Welsh version reviewed by the Trust's translators. Planned duration: about three weeks.

Dates hold with confidence for the first milestone and are confirmed again at each gate. A delay in a Trust action, such as approving the wave plan, moves the date through change control and does not change the price.
